Library Management System

Project Description

The Library Management System is a SQL-based project designed to manage library operations efficiently. It stores and manages information about books, authors, categories, library members, and book borrowing records.

Technologies Used

- MySQL
- SQL

Features

- Manage books, authors, and categories.
- Store and manage library member details.
- Issue and return books.
- Calculate fines for overdue books.
- Search books by title, author, or category.
- Track available and issued books.
- View borrowing history.
- Generate library statistics.
- Use stored procedures, triggers, and views.
- Apply indexes to improve query performance.

Database Tables

1. "authors" — Stores author information.
2. "categories" — Stores book categories.
3. "books" — Stores book details and availability.
4. "members" — Stores library member information.
5. "book_issues" — Stores book issue and return records.

Project File

- "library_management.sql" — Contains the database creation script, tables, sample data, stored procedures, triggers, views, and SQL queries.

How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench.
3. Open the "library_management.sql" file.
4. Execute the SQL script.
5. The "library_management" database will be created with the required tables and sample data.
6. Run the included queries to explore the library database.

Note: The script uses "DROP DATABASE IF EXISTS", which deletes an existing database named "library_management" before recreating it. Back up any important data before execution.
